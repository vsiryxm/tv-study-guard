# 学习守护 · TV Study Guard

> 装在安卓电视上的「防沉迷小助手」。到点了，电视自动暂停，孩子做完几道题才能继续看。不用买设备、不用注册账号、不联网也能用。

当前版本 **0.11.0**（versionCode 35）。一个 APK 走天下，最低支持 Android 4.0.4 / API 15 的电视。

## 这是什么？适合谁？

- 家里孩子看电视的时间不好控制？
- 想让孩子休息时做几道练习题，而不是简单粗暴地断网？
- 不想把家里的观看习惯上传到云端？

学习守护就是为这个场景做的：它装在你的电视上，按你定的规则到时间就弹出答题页，答完才继续看。家长用手机或电脑就能管理，**不用装家长 App、不用注册、不用连云服务**。

一句话：**电视装一个 App，手机开个网页管规则，到点做题再看。**

## 安装到电视

### 方式一：让 AI 助手帮你装（推荐小白）

把下面这段话连同本仓库地址发给能操作电脑的 AI 助手，它会引导你完成安装和授权。家长口令和暗语由你自己输入，**不用告诉助手**。

~~~text
请帮我把「学习守护 / TV Study Guard」安装到家中的安卓电视上，直接执行安装和验证，不要只给我操作教程。先阅读我提供的项目 README、安装指南和当前验收记录；缺少项目地址、电视 IP 或必要授权时，用简单的话逐项引导我，能自动检测的不要反复问。检查电脑工具和 ADB 连接，确认目标电视的型号、Android/API 版本，再选择项目提供的兼容安装包，核对版本、SHA-256 和签名；没有可用安装包时，按项目文档判断能否从源码构建，不能取得所需源码或工具时明确说明。已有安装必须保持签名一致并覆盖升级，保留口令、规则和学习记录，不能擅自卸载或清数据。安装后启动应用，协助完成悬浮窗、自启动和后台运行授权，检查该机型是否有厂商白名单限制：海信 VIDAA 和小米的处理方式不同，只采用已验证且适用于当前机型的方法，不要擅自 root、刷机、禁用系统管家或修改全局后台策略。验证版本和服务状态，并从电脑实际访问电视的 18765 管理端口；应用退到后台后继续检查至少 5 分钟，不能仅凭安装成功或网页短暂可访问就宣布完成。重启验证先征得我同意；无法获得后台权限时如实标为受限，不要反复启动应用冒充修好。最后给我可点击的家长管理网址，指导我自行登录或设置口令，并只列出仍需我确认的权限、遥控操作和实际观看遮挡。不要在家庭电视上运行会改写数据的自动化测试，不要索取或输出我的口令、暗语和登录凭证。
~~~

厂商后台限制有时仍需人工处理。小米 MiTV4-ANSM0 的后台重启限制尚未解决，不承诺所有电视都能一键成功。

### 方式二：自己动手装

1. 把 APK 拷进 U 盘插到电视，用电视自带的「文件管理 / 应用安装」打开安装；也可以用电脑 ADB 安装。
2. 首次打开 App，按电视提示允许**悬浮窗**权限，否则答题页盖不住画面。
3. 按你的电视品牌，在系统设置里允许**自启动 / 后台运行**。

详细命令和各品牌的坑见 [安装指南](docs/INSTALL_XIAOMI.md)。已有安装请覆盖升级，**不要卸载或清数据**；换过签名的包不能直接覆盖。

## 开始使用

1. 手机或电脑连到和电视**同一个家里 Wi-Fi**。
2. 电视首页会显示一个二维码和网址。用手机扫码，或在浏览器输入 `http://电视IP:18765`。
3. 第一次使用，设一个 4–12 位数字**家长口令**，再设一个 6–32 字的**家长暗语**（忘了口令时靠它找回）。手动输入网址时还要填电视上显示的 4 位连接码。
4. 在网页里设好「每隔多久休息、每天能看多久、出哪些科目的题」，然后打开守护。
5. 到点了电视会出题，答完继续看；你也能从手机随时锁屏或解锁。

几个常用操作：

- **返回观看**：把 App 放到后台；想再进首页，从电视的应用列表重新打开。
- **答题时进管理页**：按遥控器菜单键，或点答题页的「家长扫码」按钮；返回后还是原来那道题。
- **立即锁屏 / 解锁屏幕**：网页首页两个按钮，点了直接生效——锁屏启用守护并出题，解锁结束题链并关闭守护。

> 小提示：电视 IP 变了就要重新扫码。扫码本身不等于授权，仍需输入口令。

## 常见问题

**要联网吗？要注册吗？收费吗？**
不用注册、不收费。题库在电视本地，管理网页走家里局域网，不需要云账号。

**隐私怎么样？**
规则、答题记录和授权都只存在电视本机。没有广告、没有统计 SDK、不上传、不调用摄像头和麦克风。网页用家里局域网 HTTP，链路不加密，所以**不要把管理端口或 ADB 映射到公网**。详见 [隐私说明](docs/PRIVACY.md)。

**忘了家长口令怎么办？**
登录页点「登录遇到问题？→ 忘记口令」，重新扫码或填电视连接码，用你设的**家长暗语**重设口令。暗语按家庭使用取舍明文保存在电视本机，页面不回显，请务必记住。旧版恢复码和 ADB 重置后门都已移除。

**什么电视能用？**
最低 Android 4.0.4 / API 15，需要能侧载 APK、开悬浮窗、后台运行。已在海信 LED50EC280JD、小米 MiTV4-ANSM0 上做过适配；创维、长虹、康佳等**尚未实测**，不作为已适配品牌宣传。别只凭 Android 版本判断兼容性。

**手机为什么有时连不上电视网页？**
网页服务跑在电视 App 里；App 被系统杀掉、电视关机、手机连的是访客 Wi-Fi，都可能连不上。海信 VIDAA、小米等有后台清理策略，需要把 App 加进白名单。详见 [安装指南](docs/INSTALL_XIAOMI.md)。

**孩子能自己把 App 关掉吗？**
普通侧载挡不住系统强停、卸载或厂商清后台，也不保证能暂停第三方播放器或覆盖 HDMI 画面。想要更强管控可看 [设备所有者模式](docs/MANAGED_MODE.md)。

## 它怎么出题？

离线题库 3664 道，覆盖数学、语文、英语、唐诗、脑筋急转弯、十万个为什么、AI 常识。首次答对直接庆祝；首次答错重试原题，再做一道加练；到期错题优先复习。作答流水保留最近 5000 条。数学 900 道经过表达式验算，但不等于全部题目经过老师审定，见 [题库说明](docs/QUESTION_BANK.md)。

## 给开发者

需要 JDK 17、Android SDK 35 / Build Tools 35.0.0、Python 3，Gradle Wrapper 8.7。首次构建需下载依赖，已有缓存时可加 `--offline`。

~~~sh
python3 scripts/build_question_bank.py --check
python3 scripts/audit_content.py
./gradlew :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
# 仅专用模拟器，会改写测试数据，禁止在家庭电视
scripts/device-test.sh emulator-5554
~~~

发布包：设置 JAVA_HOME、ANDROID_HOME、SIGNING_KEYSTORE、SIGNING_ALIAS、SIGNING_STORE_PASS、SIGNING_KEY_PASS 后运行 scripts/package-apk.sh，输出在 dist/ 下的不可调试 APK 和 SHA256SUMS.txt。签名私钥不入库；自己编译用的是自己的签名，不能直接覆盖维护者签名的安装。
