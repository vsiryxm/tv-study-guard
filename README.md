# 学习守护 / TV Study Guard

Android TV 本地防沉迷应用：按家长规则暂停观看，完成练习后继续。电视使用原生深色首页和答题卡；家长在同一家庭网络的手机、PC 浏览器管理，无需安装家长 App、注册云账号或连接云服务。

当前版本：**0.11.0 / versionCode 35（预发布）**。一个 APK，最低 Android 4.0.4 / API 15。电视须支持 APK 侧载、悬浮窗和后台运行。不能仅凭 Android 版本判断厂商 ROM 兼容性。

## 让 AI Agent 帮你安装

把下面提示词连同本仓库地址交给能操作终端的 AI Agent。电脑与电视连接同一家庭网络，按提示在电视确认 ADB 授权。家长口令和暗语由你自行输入，无需告诉 Agent。

~~~text
请帮我把「学习守护 / TV Study Guard」安装到家中的安卓电视上，直接执行安装和验证，不要只给我操作教程。先阅读我提供的项目 README、安装指南和当前验收记录；缺少项目地址、电视 IP 或必要授权时，用简单的话逐项引导我，能自动检测的不要反复问。检查电脑工具和 ADB 连接，确认目标电视的型号、Android/API 版本，再选择项目提供的兼容安装包，核对版本、SHA-256 和签名；没有可用安装包时，按项目文档判断能否从源码构建，不能取得所需源码或工具时明确说明。已有安装必须保持签名一致并覆盖升级，保留口令、规则和学习记录，不能擅自卸载或清数据。安装后启动应用，协助完成悬浮窗、自启动和后台运行授权，检查该机型是否有厂商白名单限制：海信 VIDAA 和小米的处理方式不同，只采用已验证且适用于当前机型的方法，不要擅自 root、刷机、禁用系统管家或修改全局后台策略。验证版本和服务状态，并从电脑实际访问电视的 18765 管理端口；应用退到后台后继续检查至少 5 分钟，不能仅凭安装成功或网页短暂可访问就宣布完成。重启验证先征得我同意；无法获得后台权限时如实标为受限，不要反复启动应用冒充修好。最后给我可点击的家长管理网址，指导我自行登录或设置口令，并只列出仍需我确认的权限、遥控操作和实际观看遮挡。不要在家庭电视上运行会改写数据的自动化测试，不要索取或输出我的口令、暗语和登录凭证。
~~~

这是协助安装提示词；厂商后台限制可能仍需人工处理。当前小米 MiTV4-ANSM0 的后台重启限制尚未解决，不承诺所有电视一键成功。

## 安装与使用

1. 下载 tv-study-guard-v0.11.0.apk，核对下载页 SHA-256。已有安装覆盖升级，勿卸载或清数据；不同签名不能直接覆盖。
2. 打开电视上的学习守护，完成系统悬浮窗授权，并按机型允许自启动、后台运行。
3. 手机扫码或在 PC 浏览器输入首页显示的 http://电视IP:18765。首次设置 4–12 位数字家长口令和 6–32 字家长暗语；直接输入网址时还需电视连接码。扫码不会绕过已有口令验证。
4. 在网页设置间隔、每日时长、科目和题目范围，再开启守护。选择项即时保存，数字和文字结束编辑后保存；以电视返回成功为准。
5. 首页提供电视状态、今日用量及锁屏操作。手机右上角菜单进入规则、记录、授权等页面；PC 使用左侧导航。解锁屏幕结束题链并关闭守护，立即锁屏启用守护并出题，两者直接执行。
6. 返回观看会把应用放到后台；从电视应用列表可再次进入。答题页菜单键或家长扫码按钮打开管理入口，返回保留原题。答题完成并结束礼花后直接返回观看。

详细安装、旧海信白名单和小米限制见 [安装指南](docs/INSTALL_XIAOMI.md)。电视 IP 变化需重新扫码；访客网络、AP 隔离、VPN 可能阻断互访。应用被系统强停或电视关机时网页不可访问。

## 口令与隐私

- 无默认口令。数字口令保存带随机盐的 PBKDF2 校验值；旧海信首次验证或修改口令可能较慢。现有快速验密路径保留，未再调整算法成本；在线输错 5 次锁定 60 秒。
- 记住私人浏览器为固定 30 天，否则 2 小时。退出需二次确认，撤销立即失效；修改口令撤销其他浏览器授权。
- 家长暗语按家庭使用取舍明文保存在电视私有目录，页面不回显。忘记口令时，重新扫码或输入连接码，再以暗语设置新口令。没有旧恢复码或 ADB 重置后门。
- 规则、学习记录和授权保存在电视本地，无广告、统计 SDK、云上传、摄像头或麦克风采集。管理网页使用家庭局域网 HTTP，不保护链路上明文；不要映射管理端口或 ADB 到公网。完整说明见 [隐私说明](docs/PRIVACY.md)。

## 功能与边界

首次答对即可庆祝；首次答错则重试原题，再完成一道加练。加练答错不追加第三题。到期错题优先复习；作答流水保留最近 5000 条。

离线题库 3664 道，覆盖数学、语文、英语、唐诗、脑筋急转弯、十万个为什么、AI 常识。数学 900 道经过表达式验算，不等于全部题目已获教师审定，见 [题库说明](docs/QUESTION_BANK.md)。

普通侧载不能防止系统强停、卸载、撤权或厂商清后台，不保证暂停/静音第三方播放器或覆盖 HDMI 硬件层。小米、海信存在不同白名单限制；创维、长虹、康佳等尚未实测，不作为已适配品牌宣传。可选设备所有者模式见 docs/MANAGED_MODE.md。

## 从源码构建

需要 JDK 17、Android SDK 35 / Build Tools 35.0.0、Python 3，Gradle Wrapper 使用 8.7。通过 ANDROID_HOME 或本机 local.properties 指定 SDK。首次构建需下载依赖，已有缓存时可加 --offline。

~~~sh
python3 scripts/build_question_bank.py --check
python3 scripts/audit_content.py
./gradlew :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
# 仅专用模拟器，会改写测试数据，禁止家庭电视
scripts/device-test.sh emulator-5554
~~~

发布包：设置 JAVA_HOME、ANDROID_HOME、SIGNING_KEYSTORE、SIGNING_ALIAS、SIGNING_STORE_PASS、SIGNING_KEY_PASS 后运行 scripts/package-apk.sh。输出 dist/ 下的不可调试 APK 与 SHA256SUMS.txt。签名私钥不入库，维护者发行签名延续既有安装身份；自行编译使用自己的密钥，不能直接覆盖维护者签名版。
