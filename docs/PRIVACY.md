# 隐私说明

本项目不提供云服务，不收集或上传使用统计、设备标识或学习内容，无广告/分析 SDK，不使用摄像头、麦克风或位置。

规则、每日用量、题链、作答和错题保存在电视应用私有目录；作答流水最多 5000 条。数字口令保存带盐校验值，家长暗语明文保存，浏览器授权保存摘要。网页获得管理所需状态和记录，浏览器本地保存自己的授权凭证；勿在不可信设备勾选记住登录。

管理采用家庭局域网 HTTP，同网段攻击者可能窃听口令和授权，不适合公网部署。应用拒绝部分异常来源并不等于 HTTPS。电视应用关闭云备份；操作系统、root 用户或具高权限的厂商组件可能访问本地数据。

清除应用数据或卸载会移除本地配置、记录和凭据，并中断守护。请勿为解决升级问题直接清数据。提交反馈前请隐藏口令、暗语、二维码、连接码、授权 token 和家庭网络信息。
