# 可选受管设备保护

普通安装无需启用本模式。默认不设置系统策略，只在家长完成设备所有者配置后，才能从手机/PC 网页的“电视设备”主动开启。页面位于网页家长口令登录之后，操作还须确认。

## 能力

| 版本 / 条件 | 实际能力 |
|---|---|
| 普通安装 | 计时、覆盖、持久化、服务重启；无法禁止系统强停/卸载 |
| 设备所有者 + Android 6–10 | 对本应用设置卸载阻止；不承诺防强停/清数据 |
| 设备所有者 + Android 11+ | 另可用 setUserControlDisabledPackages 限制本应用的用户强停、清数据 |

仅读取和修改本应用包名；合并/移除自身时保留其他包的已有策略。界面读取系统实际状态，不用本地开关代替系统读回。失败时显示错误；启动服务只恢复家长之前主动开启的保护。

## 配置与退出

应用不会自动设为设备所有者。对支持 Android 企业管理、没有其他所有者且符合配置条件的专用测试设备，可使用：

```sh
adb -s 设备地址 shell dpm set-device-owner cn.studyguard.tv/.GuardAdminReceiver
```

此命令可能被机型、系统配置、现有账号和用户状态拒绝。不要为了本应用擅自清除家庭电视账号或恢复出厂。实际小米 MiTV4-ANSM0 没有声明 android.software.device_admin，未尝试配置设备所有者。

家长页面中“关闭保护”会清除本应用施加的卸载/强停/清数据限制，但仍保留设备所有者身份；“解除设备所有者”先关闭本应用策略，再请求系统移除身份，不清除电视数据。两项均需在家长登录后确认。

部分 Android TV ROM 的 clearDeviceOwnerApp 系统接口可能失败。API 33 ATV 模拟器实测在不存在的 telephony/carriers/enforce_managed 上报错，APP 会显示“策略已关闭，但系统未能解除设备所有者”，并保留失败信息；不能把这种情况记为完全解除成功。设备所有者身份本身仍可能阻止卸载。应用不调用 wipeData，也没有请求擦除设备策略。

此模式不防御 root、恢复出厂、厂商固件行为；不保证 HDMI 硬件层可覆盖。对老款小米家庭电视，先完成普通模式真机验收。
