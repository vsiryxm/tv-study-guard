# 当前交付目标

- 电视原生深色首页、答题卡和扫码/网址入口，不在电视输入家长口令或操作管理表单。
- 同一家庭网络手机、PC 响应式 HTML 管理规则、记录、授权、锁屏与解锁；没有云账号和家长端 App。
- 一个 Android 4.0.4 / API 15 起的 APK，以分版本资源适配新系统；不维护重复业务分支。
- 保留规则、口令与学习记录；删除废弃电视会话、旧题生成器、恢复码及重置入口。
- 下载页提供签名 APK、SHA-256 和对应源码；GPL-3.0 允许商用，保留版权和第三方许可。
- 以自动化覆盖核心行为；截图、家庭遥控与实际观看由用户验收。品牌后台白名单、HDMI、重启和断电不能由模拟器结果代替。

暖砂家长网页与深色电视设计沿用已确认方案。消息位于导航下方；退出需确认，锁/解锁无需确认；家长暗语单次输入并可修改。
