# 技术架构

## 模块

- core：纯 Java 计时规则、题链、错题排期、有限离线题库、二维码和一次性配对凭证。
- Android：MainActivity 原生首页/扫码，QuizView 答题、CelebrationView 礼花；GuardService 负责计时、前台通知和全屏遮挡。电视没有管理表单、WebView 或数字口令输入。
- 家长网页：ParentServer 在电视提供 parent.html 和同源 JSON API。手机单列折叠菜单、PC 侧栏，无 Node 后端、外部字体或 CDN。

## 数据与故障处理

Store 管理规则、题链状态和 SQLite 作答/错题记录。转换即时保存，用量约每 5 秒保存；异常退出可能丢失这段未落盘用量。存储失败回滚内存状态并给出错误，不返回假成功。实际遮挡状态与规则阻止状态分离，遮挡失败时继续计时，并报告系统权限问题。

ParentServer 有界线程池处理 HTTP，关闭退出连接，绑定失败重试。状态轮询不读取完整历史；网页约每 5 秒刷新，隐藏时暂停。规则保存串行并防止旧响应覆盖新编辑。

## 认证

ParentAuth 管理数字口令哈希与明文家长暗语；BrowserAuth 为唯一家长授权，最多 16 个浏览器，只保存 token 摘要、口令指纹、名称和固定到期时间。旧电视一小时会话机制已删除。

保留现用双哈希格式与旧口令读取，避免已有家庭凭据失效，尚未重新设计验密成本。首次旧凭据验证后建立带盐快速校验；后续使用快速路径。在线错误限流保留。PairingGate 提供十分钟一次性连接码/二维码票据；设置和恢复需票据，扫码不等于登录。

服务拒绝非私网来源、异常 Host/Origin、重复头、Transfer-Encoding 和超大请求。Bearer 授权不依赖跨站 cookie。HTTP 仅适合可信家庭网络，不能抵御同网段窃听。

## 单包与兼容

统一 minSdk 15。Holo/PNG 为基础资源，values-v21、values-v23、drawable-v21 提供新系统覆盖；运行时 API 判断保留以支持旧系统。删除旧生成式题库、电视管理会话、重置广播和双线打包流程。SQLite 升级及已有数据读取保留，避免清理代码造成用户数据损失。

START_STICKY 和前台服务不能越过厂商后台白名单；HDMI 覆盖、待机和重启必须实机验收，模拟器不能证明品牌兼容。
