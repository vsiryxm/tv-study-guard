# 安装、局域网使用与恢复 · v0.11.0

## 覆盖升级

先用 adb devices -l 和 getprop 确认设备。统一使用 tv-study-guard-v0.11.0.apk，最低 Android 4.0.4 / API 15。须支持侧载、悬浮窗与后台运行。包名 cn.studyguard.tv；已有安装须同签名覆盖升级，勿卸载或清数据。

~~~sh
adb -s 电视设备号 install -r /实际路径/tv-study-guard-v0.11.0.apk
adb -s 电视设备号 shell am start -n cn.studyguard.tv/.MainActivity
adb -s 电视设备号 shell dumpsys package cn.studyguard.tv
~~~

海信首启可能被桌面抢前台，再启动一次确认。海信 input keyevent 使用数字：4=返回，23=确认，82=菜单。版本应为 35 / 0.11.0。

## 使用

1. 手机/PC 与电视处于同一家庭网络。首页扫码，或输入电视显示的 http://地址:18765。
2. 首次在网页设置 4–12 位数字口令和6–32字家长暗语（直接输入地址时再填电视 4 位连接码）；已有口令直接验证。二维码不授权管理。
3. 在电视首页完成悬浮窗系统授权；自启动/后台运行按系统能力配置。网页不代按系统授权。
4. 网页选择规则即保存，数字和文字结束编辑后保存；确认“已保存 · 电视已生效”。失败显示明确原因。
5. 可收藏地址并记住私人浏览器 30 天；公共电脑取消勾选，2 小时。退出/撤销即失效。电视 IP 改变需重扫。
6. 答题卡右上角“家长扫码”或菜单键进入扫码页，返回仍是原题；无全局快捷键。

手机 Wi-Fi、电视网线可以互访，只要路由器不隔离。连不上时检查访客网络/AP 隔离/VPN、防火墙、电视开机和服务状态。不要映射管理或 ADB 端口到公网。普通应用无法保证防强停/卸载/厂商清后台，见 MANAGED_MODE.md。

## 小米 MiTV4-ANSM0 / Android 6.0.1

0.10.1 已验证覆盖升级、回桌面及短时待机唤醒后管理网页可访问。完整重启后的自动启动尚未通过；目前需从应用列表打开一次「学习守护」。此机系统日志还显示拒绝守护服务进入前台运行，因此不能据短时后台可用承诺长期保活。进一步检查已确认 ROM 的应用白名单还控制服务退出后自动重启，日志可见 scheduleServiceRestartLocked not allow service。普通 shell 无权修改 /data/system/app_control.xml，尚未找到普通用户可操作的授权入口；反复拉起应用只会临时恢复，不能作为修复方案。

## 海信 LED50EC280JD / Android 4.0.4

此机型的 VIDAA 应用管家可能在侧载数分钟后强停学习守护，电视的管理网页会随之断开。装机后把「学习守护」加入应用管家的白名单，确认应用未被列入自启动管控，并在退出首页几分钟后重开手机网页检查。系统菜单如果提供白名单，优先在电视上操作。本机已验证的维护路径依赖 root ADB，普通家庭电视若没有白名单入口，后台守护只能按受限功能验收。

维护此旧机型时，先备份 VIDAA 助手偏好，再停止管家进程，随后把 `cn.studyguard.tv` 从 `control_autostart_apps` 移到 `white_pkg_list`。恢复原属主 `1000:1000` 和权限 `660` 后再核对读回与后台存活。若先写文件，仍在运行的管家可能把旧配置写回。

## 忘记家长口令

使用在“口令与授权”中设置的家长暗语。登录页展开“登录遇到问题？”点“忘记口令”，重新扫码或填电视连接码，输入暗语并设置新数字口令。暗语可在已登录页修改，明文输入一次即可，按用户要求明文保存在电视本地，页面不回显原文。升级后未设暗语的家长可登录后补设，原数字口令继续有效。

找回保留规则、作答和错题，撤销其他浏览器授权。旧版恢复码和ADB重置入口已移除，请先登录设置暗语并妥善记住。
